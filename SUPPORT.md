# Support

App Manager is maintained on a best-effort basis and does not currently include commercial support or response-time guarantees.

- Use [GitHub Discussions](https://github.com/karerckor/app-manager/discussions) for setup and usage questions when available.
- Use [GitHub Issues](https://github.com/karerckor/app-manager/issues) for reproducible bugs and focused feature proposals.
- Use private vulnerability reporting for security issues; see [SECURITY.md](SECURITY.md).

Include the App Manager version or commit, deployment method, relevant sanitized logs, and clear reproduction steps. Never post real API keys, signing credentials, private keys, `.env` files, or customer data.
